# Notes

Long-form notes created by `scripts/new-note.mjs`, named `YYYY-MM-DD-slug.md`
so they sort chronologically.

The short version of anything important here belongs in a numbered section
(`02-projects.md`, `05-decisions.md`) — those are always loaded, while notes
are the first thing dropped when the bundle hits a size budget.

Exclude this directory from a build with `--no-notes`.
